# Watch worktree-fleet

If `$ARGUMENTS` contains `--once`, run:

```sh
worktree-fleet watch --once
```

Otherwise run:

```sh
worktree-fleet watch
```

Use the dashboard to monitor sessions, worktrees, dirty files, intents, pending updates, blocked reasons, divergent targets, and recent activity.
